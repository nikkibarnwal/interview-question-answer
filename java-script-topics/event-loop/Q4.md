Your understanding of these advanced Node.js rules is now quite solid.

The **one thing to be careful about in an Adobe interview** is this statement:

> "setTimeout(0) and setImmediate order is not fixed."

That's correct **for top-level scheduling**.

But if both are scheduled **inside an I/O callback**, `setImmediate()` generally gets the opportunity before the timer.

So remember this interview cheat sheet:

```text
Synchronous
    ↓
process.nextTick
    ↓
Promise microtasks
    ↓
Event-loop phases
    ↓
timers / poll / check ...
```

And:

```text
Top-level:
setTimeout(0) vs setImmediate
→ order can vary

Inside I/O callback:
setImmediate
→ generally before setTimeout(0)
```
