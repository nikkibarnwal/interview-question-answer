# **How do you test your code for good quality?**

I follow a mix of **manual checks, automated tests, and code quality practices** to make sure my code is clean and reliable.

---

## **1. I write clean, readable code**

- Use meaningful variable names
- Keep functions small
- Follow coding standards (ESLint, Prettier)
  Clean code automatically reduces bugs.

---

## **2. I test using unit tests**

For React/Node:

- **Jest**
- **React Testing Library**
  I write tests for:
- components behavior
- API functions
- utilities

This ensures the main logic always works.

---

## **3. I test API responses**

- Check status codes
- Validate data shape
- Test success + failure cases

This helps catch API issues early.

---

## **4. I do manual functional testing**

I run through the feature like a real user:

- click every button
- test error cases
- check boundary conditions
- test on different browsers/sizes

This ensures the UI behaves correctly.

---

## **5. I use debugging and logs**

Using browser DevTools or Node logs to validate:

- correct values
- no errors in console
- performance issues

---

## **6. I review my PRs before sending**

Self-review catches many small mistakes:

- unnecessary code
- missing validations
- wrong conditions
- missing null checks

---

## **7. Team Code Review**

I ask for peer review.
Two pairs of eyes always catch more issues.

---

# **Simple One-Line Summary:**

**I ensure code quality through unit tests, manual testing, clean coding, logs, debugging, and proper code reviews.**
